## 📌 Project Overview

This project presents an **interactive Sales Analysis Dashboard** built using **Microsoft Power BI** to analyze and visualize online sales data. The dashboard helps businesses monitor key performance indicators (KPIs), identify sales trends, evaluate profit performance, and gain actionable insights for data-driven decision-making.

The project demonstrates skills in:

✅ Data Cleaning  
✅ Data Transformation  
✅ Data Modeling  
✅ DAX Calculations  
✅ Business Intelligence Reporting  
✅ Dashboard Design  
✅ Interactive Visualizations

# 🔍 Business Insights

### 📈 Sales Performance
- Clothing category contributes the highest share of sales.
- Electronics and Furniture show significant contributions.

### 💰 Profit Trends
- Certain months generate significantly higher profits.
- Seasonal demand patterns can be identified.

### 💳 Customer Preferences
- Cash on Delivery (COD) remains the most preferred payment mode.
- UPI adoption is growing rapidly.

### 📦 Product Performance
- Printers and Bookcases contribute higher profitability.
- Accessories and Tables require further optimization.
