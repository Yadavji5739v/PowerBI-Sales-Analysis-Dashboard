# Sales Analysis Dashboard using Power BI

## Overview

This project is an interactive Sales Analysis Dashboard developed using Power BI. The dashboard provides valuable insights into sales performance, profit trends, product categories, customer behavior, and payment modes.

## Objectives

- Analyze sales and profit performance.
- Identify top-performing product categories.
- Monitor monthly profit trends.
- Understand customer payment preferences.
- Provide actionable business insights.

## Features

- KPI Cards for Total Sales, Profit, and Quantity Sold
- Monthly Profit Analysis
- Category-wise Sales Distribution
- Sub-category Performance Analysis
- Payment Mode Analysis
- Interactive Filters and Slicers
- Dynamic Dashboard Navigation

## Dataset

The dataset contains:

### Orders Table
- Order ID
- Order Date
- Customer Name
- State
- City

### Details Table
- Amount
- Profit
- Quantity
- Category
- Sub-Category
- Payment Mode

## Technologies Used

- Power BI
- DAX
- Power Query
- Excel

## Dashboard Insights

- Clothing contributes the highest sales volume.
- COD is the most preferred payment method.
- Monthly profit analysis highlights seasonal business trends.
- Sub-category analysis identifies top-performing products.
